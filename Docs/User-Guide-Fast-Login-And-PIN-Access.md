## 1. Overview of Fast Sign-In

In high-volume retail stores, supermarkets, and busy restaurants, staff sign in and out dozens of times per shift. Fast PIN Access eliminates typing lengthy passwords and opens your active workstation in less than a second.

---

## 2. How to Use PIN Sign-In (POS & Mobile)

```
+-------------------------------------------------------+
|  RetailPOS Enterprise Terminal                        |
|-------------------------------------------------------|
|  Outlet: [ OUTLET001 - Downtown Flagship          ▼ ] |
|                                                       |
|  [ Password Sign-In ]       [ ⭐ Quick PIN Sign-In* ] |
|-------------------------------------------------------|
|  Staff Member:                                        |
|  [ 👤 Alex Rivera (Cashier / Shift Lead)          ▼ ] |
|                                                       |
|  Enter Employee PIN:                                  |
|  [ • • • •                                          ] |
|                                                       |
|             [ 1 ]    [ 2 ]    [ 3 ]                   |
|             [ 4 ]    [ 5 ]    [ 6 ]                   |
|             [ 7 ]    [ 8 ]    [ 9 ]                   |
|           [CLEAR]    [ 0 ]    [ ⌫ ]                   |
|                                                       |
|          [ 🚀 SIGN IN TO WORKSTATION -> ]             |
+-------------------------------------------------------+
```

1. Select your **Outlet** from the top dropdown.
2. Select the **Quick PIN** tab.
3. Pick your name from the **Staff Member** dropdown.
4. Tap your 4 to 6 digit PIN.
5. Click **Sign In** (or the screen will auto-submit upon entering the last digit).

---

## 3. Zero-Lag Terminal Launch

Once you enter your PIN, the application immediately routes you to your workstation without waiting for background license pings or checklist scans:
- **Waiters / Captains**: Lands directly on the active Table Floor Grid.
- **Cashiers**: Lands directly on the Retail POS Billing Terminal.
- **Kitchen Staff**: Lands directly on the Kitchen Display System (KDS).
- **Store Managers**: Lands on the Master Dashboard.

---

## 4. Setting Your Favorite Startup Screen

If you prefer logging directly into a specific screen on your terminal:
1. Go to **Settings** $\rightarrow$ **System Settings** $\rightarrow$ **Workstation Configuration**.
2. Under **Default Startup Screen**, choose your preferred screen:
   - *Main Dashboard*
   - *Retail POS Billing*
   - *Restaurant Floor & Captain Console*
   - *Kitchen Display System (KDS)*
   - *Retailer Operations Console*
3. Save settings.

---

## 5. Troubleshooting & Quick Tips

- **Forgot PIN?** Click the **Password** tab and log in with your primary store password. An administrator can reset your PIN in **User Management** at any time.
- **Offline Sign-in**: Fast PIN sign-in works seamlessly on your local store network even if external internet connectivity is disconnected.
